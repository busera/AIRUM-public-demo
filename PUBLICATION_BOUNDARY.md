# AIRUM public demo repository

This repository is intentionally a reduced public introduction. It does not contain the private AIRUM implementation, full risk matrix, internal rules, scoring logic, private mappings, source captures, build database, operational exports, or audit working material.

The public demo uses disclosure-safe source labels and summaries only. It must not expose licensed excerpts, internal extraction paths, local vault paths, private Obsidian references, or detailed source-to-control rationale from the internal AIRUM working version.

Do not describe this repository as source-perfect validation, legally validated conclusions, or ready-to-use final audit workpapers. The correct public framing is that AIRUM is a pre-discovery preparation aid: internally source-supported where private provenance is retained, but not a publication of every underlying source, rationale, legal interpretation, or engagement-specific workpaper conclusion.

Use this repository for:

- public project introduction;
- university / research discussion links;
- conference or guest speaker context;
- Medium article support material.

Do not add private implementation artifacts here unless they have been separately sanitized and reviewed for publication.


## Public/private provenance decision table

| Information type | Internal AIRUM | Public Demo |
|---|---:|---:|
| Source family label | Yes | Yes |
| Public source URL | Yes | Yes, if disclosure-safe |
| Licensed-source locator | Yes | No |
| Local vault path | Yes | No |
| Source extract | Yes, if permitted internally | No |
| Source-to-control rationale | Yes | Summary only |
| Legal interpretation | Contextual only | No legal conclusion |
| Audit workpaper conclusion | No; requires engagement tailoring | No |

Public copy should use “disclosure-safe source labels” or “source families” rather than implying publication of the full source basis. Legal and regulatory references should be framed as risk prompts that require legal/compliance review, not as legal mappings or validated legal conclusions.
